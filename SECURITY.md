# Security Policy

## Supported Versions

The `1.1.x` release series receives security fixes.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Lyl101010/antigravity-codex-monitor/security/advisories/new). Include the affected version, a description of the impact, and steps to reproduce the issue.

If private reporting is unavailable, open a [repository issue](https://github.com/Lyl101010/antigravity-codex-monitor/issues/new) requesting a private channel. Keep sensitive details out of the public issue.
